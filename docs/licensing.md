# Licensing recommendation

No `LICENSE` has been applied in this initial portfolio. The owner can choose how others may reuse original material before adding the appropriate full license text.

A practical option is **MIT for original code/configuration examples** and **CC BY 4.0 for original documentation and diagrams**, with the scope stated explicitly in the README and separate license files. A single MIT license is a simpler alternative if the owner prefers one permissive license across original material.

Do not relicense OPNsense, Proxmox, Suricata, Wazuh, ET Open rules, external feed data or third-party images. Linking to upstream projects does not bring their software into this repository. No third-party ruleset or feed is bundled here.

Official texts to review: [MIT](https://opensource.org/license/mit) and [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
